Pengertian Algoritma

Algoritma adalah urutan langkah-langkah logis dan sistematis untuk menyelesaikan suatu masalah atau mencapai tujuan tertentu.

Ciri-ciri algoritma yang baik

  • Memiliki input (nol atau lebih) dan output (minimal satu).
  • Setiap langkah jelas dan tidak ambigu.
  • Berhingga: pasti berakhir.
  • Efektif: dapat dikerjakan dan menyelesaikan masalah.
  • Urutan langkah logis.

Analogi Dunia Nyata

☕ Menyeduh Kopi

  1. Panaskan air hingga mendidih
  2. Masukkan 1 sendok kopi dan gula ke gelas
  3. Tuang air panas ke gelas
  4. Aduk hingga larut
  5. Kopi siap diminum
Jika urutan diacak (mengaduk sebelum menuang air), hasilnya salah. Program juga begitu: urutan menentukan hasil.

🍳 Resep Makanan

Resep = algoritma.
Bahan = input.
Proses memasak = proses.
Makanan jadi = output.

Coba pikirkan!

Tuliskan 5 langkah algoritma untuk "mengirim pesan WhatsApp".

Ada 3 cara menuliskan algoritma: kalimat deskriptif, pseudocode, dan flowchart.

A. Kalimat Deskriptif

Ditulis dengan bahasa sehari-hari secara berurutan. Contoh: menghitung luas persegi panjang.

  1. Mulai
  2. Baca panjang dan lebar
  3. Hitung luas = panjang × lebar
  4. Tampilkan luas
  5. Selesai

B. Pseudocode

Kode "semu" yang mirip bahasa pemrograman tetapi tidak terikat bahasa tertentu, sehingga mudah dibaca manusia.

Contoh 1: Input dua angka dan jumlahkan 
ALGORITMA PenjumlahanAngka
DEKLARASI
   a, b, hasil : integer
DESKRIPSI
   INPUT a
   INPUT b
   hasil ← a + b
   OUTPUT hasil
Contoh 2: Cek kelulusan (KKM = 75) 
ALGORITMA CekKelulusan
DEKLARASI
   nilai : integer
DESKRIPSI
   INPUT nilai
   IF nilai >= 75 THEN
      OUTPUT "LULUS"
   ELSE
      OUTPUT "REMEDIAL"
   END IF

C. Flowchart (Diagram Alir)

Penggambaran algoritma dengan simbol-simbol standar.

Aturan dasar flowchart

  • Alur dari atas ke bawah atau kiri ke kanan.
  • Hanya ada satu Start.
  • Simbol Decision punya minimal dua jalur keluar (Ya/Tidak).
  • Setiap alur harus berujung di End.

Coba Sendiri: Flowchart Cek Kelulusan

Masukkan nilai, lalu lihat jalur mana yang dilalui algoritma.

Output akan tampil di sini.

1. Sekuensial (Runtutan)

Instruksi dijalankan satu per satu dari atas ke bawah, tanpa melompat.

INPUT panjang
INPUT lebar
luas ← panjang * lebar
OUTPUT luas
🔎 Analogi: mengikuti langkah cuci tangan 6 langkah secara berurutan.

2. Percabangan / Pemilihan (If-Else)

Program memilih jalur berdasarkan kondisi.

INPUT umur
IF umur >= 17 THEN
   OUTPUT "Boleh membuat SIM"
ELSE
   OUTPUT "Belum cukup umur"
END IF
🔎 Analogi: "Jika hujan, bawa jas hujan; jika tidak, pakai jaket saja."

Percabangan banyak kondisi:

IF nilai >= 90 THEN OUTPUT "A"
ELSE IF nilai >= 80 THEN OUTPUT "B"
ELSE IF nilai >= 70 THEN OUTPUT "C"
ELSE OUTPUT "D"
–

3. Perulangan / Looping

FOR (jumlah pengulangan sudah diketahui)

FOR i ← 1 TO 5 DO
   OUTPUT "Halo, Dunia!"
END FOR

WHILE (diulang selama kondisi benar)

saldo ← 0
WHILE saldo < 50000 DO
   saldo ← saldo + 10000
END WHILE
OUTPUT saldo
Awas infinite loop! Pastikan ada perubahan nilai yang akhirnya membuat kondisi menjadi salah.
🔎 Analogi: FOR = lari 10 putaran lapangan. WHILE = lari sampai napas habis.
–

Algoritma Ada di Mana-mana

  • Kalkulator → algoritma sekuensial
  • Login aplikasi → percabangan (password benar/salah)
  • Game → perulangan (game loop)

Studi Kasus: Rekomendasi Video YouTube (disederhanakan)

  1. Kumpulkan data: video yang ditonton, durasi tonton, like, pencarian.
  2. Analisis pola: topik apa yang sering kamu tonton?
  3. Cocokkan: cari video bertopik serupa atau yang ditonton orang berminat sama.
  4. Beri skor: urutkan dari yang paling mungkin kamu suka.
  5. Tampilkan daftar teratas di beranda.
INPUT riwayat_tonton
topik_favorit ← CariTopikTerbanyak(riwayat_tonton)
FOR setiap video IN daftar_video DO
   IF video.topik = topik_favorit THEN
      TambahkanKeRekomendasi(video)
   END IF
END FOR
OUTPUT daftar_rekomendasi

IF pertanyaan MENGANDUNG "jadwal" THEN OUTPUT "Jadwal ada di menu Akademik"

Tujuan Pembelajaran

  1. Menganalisis masalah sehari-hari menjadi langkah-langkah algoritma.
  2. Menulis algoritma dalam bentuk pseudocode dengan struktur sekuensial, percabangan, dan perulangan.
  3. Menggambar flowchart dengan simbol yang tepat.
  4. Menjelaskan alur logika penyelesaian masalah secara runtut.

Alat dan Bahan

  • Laptop/HP dengan koneksi internet
  • Canva (aplikasi atau browser)
  • Buku catatan dan alat tulis
